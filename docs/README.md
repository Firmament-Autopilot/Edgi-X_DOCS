# Edgi-X使用手册

**Edgi-X**是由FMT、RT-Thread团队联合Infineon打造的一款专业级、高性能的自驾仪硬件。该飞控搭载了最新的PSOC边缘E83芯片，具有M55和M33双核架构，可实现高性能和细粒度的功率优化。 

PSOC™ Edge E83系列Arm® Cortex®-M微控制器（MCU）兼具高性能与低功耗，并具备安全特性，同时集成先进的机器学习（ML）加速功能，面向下一代应用场景。该系列MCU基于Arm Cortex-M55，支持Helium DSP，并搭配Ethos-U55 NPU；同时配备低功耗Cortex-M33，并结合英飞凌的超低功耗NNLite硬件加速器，旨在加速机器学习与人工智能应用中的神经网络运算。

Edgi-X除了提供标准的外部接口，如UART、IIC、USB等，还提供了CAN总线、GPS、DSM、RC\SBUS、AD&IO、SDCard和ETH以太网接口,以及多达16路PWM输出接口和双电源接口，满足工业场景应用和网络高带宽数据传输场景。Edgi-X具有体积小、重量轻，结构尺寸为88mm * 44mm * 18mm（长宽高），重量仅为59g。

Edgi-X搭载了FMT固件，可用于无人机，无人车，无人船和机器人等应用领域。FMT是下一代开源智驾仪系统，支持基于模型开发（Model-based-design，MBD）。使用MATLAB/Simulink以图形化方式快速搭建算法模型，一键代码自动生成轻松部署到飞控硬件上，大大提高科研和研发效率，是先进算法验证、二次开发的理想平台。
