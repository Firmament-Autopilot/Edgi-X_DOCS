# 校准电调

电调一般无需校准，但若接上飞控后电调发布嘀嘀嘀报警声或者各个电机转速明显不一致，可对电调进行重新校准。

电调校准将更新电调的最大和最小 PWM 输入值，以确保每一个电调对 PWM 值都有相同的响应。不同的电调可能校准方式不同，具体请参阅对应电调的说明，这里仅针对普通的电调校准方法进行说明：

- 飞控用USB上电
- 将对应电机输出设置为最大值 (比如2000)
- 连接电池，给电机和电调上电
- 在听到提示音后将对应电机输出设置为最小值（比如1000）
- 校准完成

> 注意：电调校准时为了安全，请务必将电机桨叶卸下！

我们可以使用飞控提供的`act`指令来输出特定的PWM信号以进行校准。首先我们需要先禁止控制器的输出，以防止它覆盖指令的输出。我们可以使用如下指令来禁止控制器的输出：

```
mcn suspend control_output
```

然后使用如下指令将main_out设备对应所有的PWM通道值设置为最大2000的输出

```
act set --all -d main_out 2000
```

连接电池给电调和电机上电，听到电调的滴滴提示音后，将PWM设置为最小1000的输出即完成校准

```
act set --all -d main_out 1000
```

完成后可以输入如下指令恢复控制器输出，或者输入`reboot`重启飞控。

```
mcn resume control_output
```
